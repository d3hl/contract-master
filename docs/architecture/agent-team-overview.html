Contract Master Agent Team · High-Level Architecture

Linear issue → Orca coordinator → Claude plan → DeepSeek build → Codex verify + merge → Claude confirm → Linear Done

Primary path

  • ① A human writes an issue with goal, scope, acceptance, checks and base SHA
  • ②–③ The Orca coordinator reads the full issue; the manager triages, claims a workspace and queues it
  • ④–⑥ Claude plans, DeepSeek implements, Codex verifies the exact output SHA
  • ⑦–⑨ Codex approves and merges; Claude confirms the merged commit
  • ⑩ The outbox writes Done to Linear, and only after ⑨

Trust boundaries

  • • Only the coordinator calls the manager API and holds its tokens
  • • Workers return JSON only; issue text and results are untrusted data
  • • The context bundle is pinned per task and mounted read-only
  • • Secrets stay in 1Password; config holds op:// references only
  • • A human's change request blocks completion and escalates
